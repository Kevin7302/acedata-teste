### Avaliação Técnica - Acedata Software

- Projeto desenvolvido em JavaScript (Node.js) como parte do processo seletivo para vaga de estágio.

# Funcionalidades:

- Exercício 1 - Cálculo de Salário

* Cálculo do salário bruto;
* Cálculo do salário família;
* Cálculo do salário líquido.

- Exercício 2 - Sequência Numérica

* Leitura de uma sequência de número com entrada feita pelo usuário;
* Identificação do maior e menor valor da sequência.

- Exercício 3 - Sequência de Fibonacci

* Geração da sequência de Fibonacci;
* Verificação de pertencimento do número digitado pelo usuário à sequência .

# Tecnologias Utilizadas:

- JavaScript;
- Node.js.

# Como Executar:

- Clone o repositório:
    - git clone
- Acesse a pasta:
    - cd acedata-teste
- Execute o programa:
    - node app.js
